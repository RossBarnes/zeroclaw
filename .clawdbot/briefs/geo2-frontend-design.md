# GEO2 Frontend Design
Design and implement an intentional, production-lean frontend foundation for GEO2.

Requirements:
- Establish a coherent visual system (typography, color variables, spacing, motion)
- Build core app shell layout for desktop + mobile
- Add at least one high-value initial page/screen that demonstrates the design language
- Ensure accessibility basics (semantic landmarks, contrast, keyboard navigability)
- Keep implementation maintainable and aligned to existing repo patterns

Non-goals:
- No speculative large-scale redesign of unrelated backend systems
- No fake/mock-heavy architecture detached from real app routes

Acceptance criteria:
- UI compiles and runs in the existing app
- Mobile and desktop responsive behavior is validated
- PR includes Screenshot: line with before/after (or new screen)
